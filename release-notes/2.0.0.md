## Gravit Next 2.0.0

**Freedom lies beyond the limits.**

Gravit Next is a free, offline vector design app that opens your Gravit Designer files. No account, no cloud, no subscription.

### What's new

- **Guides.** Drag guides out of the rulers, place them exactly with Manage Guides, lock them with Lock Guides, and move the ruler origin.
- **Illustrator import.** Open, place or drop `.ai` files. Files saved with PDF compatibility import as vectors, and old PostScript-based `.ai` files open through the EPS importer.
- **Desktop files.** Open and Save As with the system dialogs, a recent files list, and `.gvdesign` files that open from your file manager.
- **A new look.** The gravitnext wordmark, a magenta accent and a neutral dark interface.
- **Updated help.** The user guide is rebranded as Gravit Next, documents the guide tools, and its links all work from inside the app.
- **Leaner package.** The AppImage is stored uncompressed and ships English only, which makes it start faster.

### What's gone

Cloud sync, sharing and comments, and templates from the cloud. They depended on servers that no longer exist.

### Download

- **Windows:** `Gravit-Next-Setup-2.0.0.exe`. The installer is unsigned, so Windows SmartScreen will warn you. Click **More info**, then **Run anyway**.
- **macOS:** `Gravit-Next-2.0.0.dmg` for Intel, or `Gravit-Next-2.0.0-arm64.dmg` for Apple Silicon. The app is unsigned, so the first time, right-click it and choose **Open**.
- **Linux:** `Gravit-Next-2.0.0.AppImage`, or the `.deb` package. For the AppImage, make it executable (`chmod +x Gravit-Next-2.0.0.AppImage`) and run it. If it does not start on a recent Ubuntu, install `libfuse2`.

Found something broken or different from what you expect? Please [open an issue](https://github.com/selwynorren/Gravit-Next/issues).
