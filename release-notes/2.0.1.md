## Gravit Next 2.0.1

A fix release.

### What's fixed

- **Right-click menus stopped opening.** After a very quick drag of an object, the canvas, Layers and Pages right-click menus could stop appearing until a slower drag happened. They now keep working, so Duplicate Page, Combine and the other menu actions stay available.

### Download

- **Windows:** `Gravit-Next-Setup-2.0.1.exe`. The installer is unsigned, so Windows SmartScreen will warn you. Click **More info**, then **Run anyway**.
- **macOS:** `Gravit-Next-2.0.1.dmg` for Intel, or `Gravit-Next-2.0.1-arm64.dmg` for Apple Silicon. The app is unsigned, so the first time, right-click it and choose **Open**.
- **Linux:** `Gravit-Next-2.0.1.AppImage`, or the `.deb` package. For the AppImage, make it executable (`chmod +x Gravit-Next-2.0.1.AppImage`) and run it. If it does not start on a recent Ubuntu, install `libfuse2`.

Found something broken or different from what you expect? Please [open an issue](https://github.com/selwynorren/Gravit-Next/issues).
